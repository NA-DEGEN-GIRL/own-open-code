# Contributing

own-open-code is a personal project, shared as is. Issues and pull requests are turned off, and there is no support.

You are free to fork it under the licences in `LICENSE` and `own/THIRD-PARTY-NOTICES.md`. Problems that also happen in
upstream OpenCode belong to [the OpenCode project](https://github.com/anomalyco/opencode); please do not report this
fork's problems there.
