# 부록 C. Claude에게 맡길 일과 내가 할 일

이 앱은 이 저장소(`D:\own-open-code`)에서 일하는 **Claude**(AI 개발 도우미)가 만들고 고치고 빌드해요. 대부분은 Claude에게 말로 부탁하면 되지만, **내 PC의 보안과 진짜 계정**에 닿는 일은 언제나 내가 직접 해요.

## Claude에게 부탁하면 되는 것

| 이렇게 말하면 | Claude가 하는 일 |
|---|---|
| “새로 빌드해 줘” | 설치 파일을 만들어요. 결과는 저장소의 `own\.out\build\<version>\desktop` 폴더에 생겨요(약 10분) |
| “테스트 전부 돌려 줘” | 형식 검사와 시험을 돌리고 결과를 알려 줘요 |
| “이 오류 고쳐 줘”, “이 기능 넣어 줘” | 코드를 고치고 시험한 뒤 저장(커밋)하고 올려요 |
| “upstream 최신으로 맞춰 줘” | 원래 OpenCode의 새 버전을 이 판에 합쳐요 |
| “설정 파일 확인해 줘” | `opencode.jsonc`의 플러그인 목록 같은 것을 확인하고 고쳐요 |
| “이 로그 봐 줘” | 증상 문구, `own status` 결과, 로그를 보고 원인을 찾아요([27장](27-data-logs-uninstall.md)) |
| “컴퓨터 사용에서 이 앱도 막아 줘” | 설정 파일의 `own-computer-use` 항목에 추가 거부 앱을 넣어요([18장](18-computer-use.md)) |
| “설명서 고쳐 줘” | 이 설명서의 Markdown을 고치고 HTML을 다시 만들어요 |

## 내가 직접 하는 것

| 일 | 왜 직접 해요? | 장 |
|---|---|---|
| **설치 파일 실행**(설치·업데이트) | Claude 데스크톱 앱 안에서 실행하면 파일이 그 앱 전용 폴더로 들어가 설치가 안 돼요. **탐색기에서 두 번 눌러** 실행해요 | [2장](02-install-update.md) |
| 제거(Windows `설정` > 앱) | 내 데이터를 지우는 일이라서요 | [27장](27-data-logs-uninstall.md) |
| 실제 API 키 넣기, ChatGPT 로그인, 이전 앱 가져오기 | 진짜 비밀 값은 Claude가 대신 입력하지 않아요 | [3장](03-first-account.md) |
| Claude 구독 계정 연결과 Claude Code 로그인(`Claude 계정 추가`, `다시 로그인` 포함) | 약관 위험이 있는 선택이라 내가 판단해요. 플러그인은 앱에 들어 있어서 따로 설치하지 않아요 | [3장](03-first-account.md), [20장](20-account-kinds.md) |
| 방화벽, 사용자 계정 컨트롤(UAC), SmartScreen 창에 답하기 | Windows 보안 설정이라서요. 이 앱은 방화벽 허용이 필요 없어요 | [2장](02-install-update.md) |
| Tailscale 설치·로그인, `tailscale serve` 실행, 공유기 포트 전달, 관리자 PowerShell 명령 | 내 네트워크를 밖에 여는 일이라서요 | [24장](24-phone-other-pc.md) |
| 휴대폰에 APK 설치(출처를 알 수 없는 앱 허용) | 휴대폰 보안 설정이라서요 | [24장](24-phone-other-pc.md) |
| SSH 호스트 키 지문 비교, ssh-agent 켜기 | 진짜 그 서버인지는 내가 확인해야 해요 | [22장](22-ssh-remote.md) |
| 기기 연결 요청에서 확인 번호 비교하고 `허용` | 양쪽 번호가 같은지 눈으로 봐야 해요 | [24장](24-phone-other-pc.md) |
| 컴퓨터 사용 켜기(세션마다 동의) | 에이전트가 진짜 마우스·키보드를 쓰게 되니까요 | [18장](18-computer-use.md) |

> **주의** 실제 키나 비밀번호를 대화에 붙여 넣지 마세요. 대화 내용은 모델 회사로 가요. 키는 언제나 `계정 추가` 화면에만 넣어요.

## 함께 하면 좋은 것

- **문제가 생겼을 때**: 화면에 보인 문구를 그대로 복사해 Claude에게 보여 주세요. 설명서 HTML의 검색 상자에 같은 문구를 넣어 [26장](26-troubleshooting.md)의 해당 줄을 먼저 찾아봐도 좋아요.
- **새 버전을 쓸 때**: Claude가 빌드를 끝내면 설치 파일 경로를 알려 줘요. 그 파일을 탐색기에서 직접 실행하면 돼요.
