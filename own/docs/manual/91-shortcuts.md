# 부록 B. 단축키

키는 Windows 기준이에요. `Ctrl+/`를 누르면 앱 안에서도 전체 목록을 볼 수 있고, `설정` > `단축키`에서 다른 키로 바꾸고 겹치는 키를 확인해요.

> **참고** 한국어 글자를 조합하는 중에는 보내는 키(`Ctrl+Enter`, 또는 `Enter`)를 뺀 단축키가 모두 무시돼요. 글자가 엉키지 않게 하려고요. 터미널이나 앱 안 브라우저에 포커스가 있으면 `Ctrl+K`, `Ctrl+Alt+B`, 패널 탭 단축키, 분할 칸 옮기기(`Ctrl+Alt+1`–`4`, `F6`, `Shift+F6`)만 앱이 받아요. 데스크톱 앱은 `Ctrl+N`, `Ctrl+W`, `Ctrl+R`을 쓰지 않아요.

## 어디서나

| 하고 싶은 것 | 키 |
|---|---|
| 명령 팔레트 | `Ctrl+K` |
| 모델 @ 계정 전환기 | `Ctrl+.` 또는 `Ctrl+'` |
| 에이전트 바꾸기(순환) | `Ctrl+Shift+.` |
| 사이드바 접기·펴기(입력창 밖에서) | `Ctrl+B` |
| 작업 패널 열기·닫기 | `Ctrl+Alt+B` |
| 작업 패널: 리뷰 | `Ctrl+Shift+R` |
| 작업 패널: 파일 트리 | `Ctrl+\` |
| 작업 패널: 터미널 | `` Ctrl+` `` |
| 작업 패널: 계정·한도 | `Ctrl+Shift+U` |
| 앱 안 브라우저를 대화 옆에 열기·닫기(데스크톱 앱. `탭으로 보기`에서는 `대화`·`브라우저` 탭 오가기) | `Ctrl+Shift+B` |
| 파일 빠른 열기 | `Ctrl+P` |
| 새 터미널 | `Ctrl+Alt+T` |
| 새 대화(지금 보는 서버) | `Alt+N` |
| 폴더 열기(지금 보는 서버) | `Ctrl+O` |
| 서버 묶음·프로젝트를 위 / 아래로 옮기기(그 머리줄에 포커스가 있을 때) | `Ctrl+Shift+↑` / `Ctrl+Shift+↓` |
| 이전 / 다음 세션 | `Alt+↑` / `Alt+↓` |
| 뒤로 / 앞으로 | `Ctrl+[` / `Ctrl+]` |
| 이전 / 다음 메시지 | `Ctrl+Alt+[` / `Ctrl+Alt+]` |
| 세션 안에서 찾기 | `Ctrl+F` |
| 입력창으로 가기 | `Ctrl+L` |
| 세션 정보 | `Ctrl+I` |
| 승인 모드 메뉴 | `Ctrl+Shift+A` |
| MCP 목록 | `Ctrl+;` |
| 설정 | `Ctrl+,` |
| 아이디어 적기(아이디어 노트) | `Ctrl+Alt+I` |
| 대화만 보기 켜기/끄기 | `Ctrl+Alt+R` |
| 지금 연 세션 보관·보관 해제(입력창 밖에서) | `Ctrl+Alt+Backspace` |
| 단축키 도움말 | `Ctrl+/` |
| 승인 요청 상자로 가기 | `Ctrl+Shift+Enter` |
| 고른 줄을 입력창 칩으로 | `Ctrl+Shift+L` |
| 확대 / 축소 / 원래 크기(데스크톱 앱, 크기를 기억해요) | `Ctrl+=`(또는 `Ctrl`+숫자패드 `+`) / `Ctrl+-` / `Ctrl+0`, `Ctrl`+휠 위·아래 |
| 컴퓨터 사용 모두 멈추기(어느 창에서나) | `Ctrl+Alt+Shift+Q` |
| 음성 입력(누르고 있는 동안 녹음, 짧게 누르면 켜고 끄기) | `Ctrl+Alt+V` |
| 완전 종료…(데스크톱 앱. `완전 종료`·`앱만 종료`·`취소`를 묻고, 처음 단추는 `취소`) | `Ctrl+Q` |

## 분할 칸에서

분할은 넓은 창에서 `나란히` 보기일 때 써요([19장](19-browser-pane.md)).

| 하고 싶은 것 | 키 |
|---|---|
| 오른쪽에 대화 칸 하나 더 열기 | `Ctrl+Alt+\` |
| 아래에 대화 칸 하나 더 열기 | `Ctrl+Alt+Shift+\` |
| 지금 칸 닫기(칸이 하나면 아무 일도 없어요) | `Ctrl+Alt+W` |
| 1–4번 칸으로 가기(위에서 아래, 왼쪽에서 오른쪽 순서) | `Ctrl+Alt+1` – `Ctrl+Alt+4` |
| 다음 / 이전 영역(사이드바 → 칸들 → 작업 패널) | `F6` / `Shift+F6` |
| 사이드바 세션을 옆 칸에 열기 | 세션 줄을 `Ctrl`+클릭 |

## 입력창에서

| 하고 싶은 것 | 키 |
|---|---|
| 보내기 / 줄 바꾸기 | `Ctrl+Enter` / `Enter`, `Shift+Enter` (`보내는 키`가 `Enter로 보내기`면 `Enter` / `Shift+Enter`) |
| 실행 중: 끼워 넣기 / 대기열 | `Ctrl+Enter` / `Alt+Enter` (`Enter로 보내기`면 `Enter` / `Ctrl+Enter`. 둘의 역할은 `설정` > `일반` > `실행 중 보내기 동작`에서 바꿈) |
| 보내는 키 바꾸기 | `전송` 옆 `▾`, `설정` > `일반` > `보내는 키`, 명령 팔레트 `보내는 키 바꾸기` |
| 실행 멈추기 | `Esc` 두 번 |
| 파일 첨부 | `Ctrl+U` |
| 셸 모드 들어가기 / 나가기 | 줄 맨 앞 `!` 또는 `Ctrl+Shift+X` / 빈 입력에서 `Esc` 또는 `Ctrl+Shift+E` |
| 백그라운드로 보내기(오래 걸리는 명령·하위 에이전트) | `Alt+B` |
| 대기열 첫 메시지 고치기 | `Ctrl+↑` |
| 지난 입력 다시 쓰기 | `↑` / `↓` |
| 명령 고르기 / 파일 이름 넣기 | 맨 앞 `/` / `@` 다음에 이름 |

## 승인 요청 상자에서

| 하고 싶은 것 | 키 |
|---|---|
| 한 번 허용 | `Enter` |
| 항상 허용 | `Ctrl+Enter` |
| 거절(이유 쓰기) | `Esc` |

## 노트에서

| 하고 싶은 것 | 키 |
|---|---|
| 대화 메모 저장 | `Ctrl+Enter` |
| 프로젝트 노트 바로 저장(적는 대로 저장돼요) | `Ctrl+S` |
| 아이디어 적기 칸: 붙이기 / 줄 바꾸기 / 닫기(적던 글은 남아요) | `Enter` / `Shift+Enter` / `Esc` |
| 아이디어 쪽지 고치기: 저장 / 취소 | `Ctrl+Enter` / `Esc` |
| 음성 입력(포커스가 노트에 있으면 노트에) | `Ctrl+Alt+V` |
