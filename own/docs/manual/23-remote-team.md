# 23. 원격 서버에서 팀 모드

**한 줄 요약** — SSH로 연결한 서버의 프로젝트에서도 팀 모드([17장](17-team-mode.md))를 그대로 켤 수 있어요. 팀 메인, 담당, 영역 폴더가 모두 서버에서 일하고, 화면과 조작은 이 PC와 똑같아요.

> **참고** 이 장은 [17장 팀 모드](17-team-mode.md)와 [22장 SSH 원격 프로젝트](22-ssh-remote.md)를 읽었다고 보고 설명해요. 이 장에는 따로 찍은 화면이 없어요. 메뉴와 카드는 17장의 그림과 같아요.

## 왜 필요해요?

- 큰 프로젝트일수록 서버에서 여러 일을 나란히 돌리는 편이 빨라요. 빌드와 시험이 서버의 힘을 써요.
- 영역 폴더(작업 폴더)가 서버 디스크에 생기니 이 PC의 디스크를 차지하지 않아요.
- 계정과 한도는 여전히 이 PC 하나에서 관리해요. 서버에는 출입증만 잠깐 빌려 줘요([22장](22-ssh-remote.md)).

| 어디 | 무엇이 있나요 |
|---|---|
| **이 PC** | 앱 화면, 계정 금고, 프리셋 |
| ↕ SSH 연결 | 화면과 출입증만 오가요 |
| **서버**(예: devbox) | 팀 메인 대화(일을 나눠 맡김), 영역마다 작업 폴더 + 담당 대화, 프로젝트 본 코드(끝난 일이 반영되는 곳) |

## 이렇게 써요

1. [22장](22-ssh-remote.md)대로 서버를 연결하고, 그 서버의 프로젝트 폴더에서 세션을 하나 만들어요.
2. 사이드바에서 그 프로젝트 머리줄의 `⋯`를 누르고 `팀 모드 켜기…`를 고른 뒤 창의 `켜기`를 눌러요.
3. 이후는 이 PC의 팀과 같아요. 요약 카드를 확인하고, 팀 메인에게 일을 말하고, `메인 멈춤`, `이 영역 반영하기`, `영역 끝내기…` 같은 메뉴를 그대로 써요([17장](17-team-mode.md)).

- 영역 폴더는 서버에서 메인 폴더 옆에 만들어져요.
- 영역의 프리셋은 **이 PC의 프리셋**이 서버로 옮겨진 것이에요. 이 PC에서 프리셋을 고치면 서버의 팀도 따라가요.

## 큰 파일(Git LFS) 저장소일 때

> **용어** Git LFS: 그림, 소리, 모델 같은 큰 파일을 Git이 따로 보관하는 방법이에요. 이런 저장소를 다루려면 `git-lfs`라는 도구가 서버에 있어야 해요.

서버에 `git-lfs`가 없어도 괜찮아요. 앱이 알아서 준비해요.

1. 팀 모드를 켜면 앱이 서버에 큰 파일 도구가 있는지 봐요.
2. 없으면 `원격 호스트에 큰 파일 도구를 준비하는 중…`이 보여요. 이 PC의 설치판에 들어 있는 고정 버전 `git-lfs`를 SSH로 서버에 **한 번** 올려요.
   - 서버의 내 홈 폴더 안에만 두어요. 관리자 권한(sudo)을 쓰지 않아요.
   - 서버의 `~/.gitconfig`는 바꾸지 않아요. 그 저장소 안의 설정에만 큰 파일 처리를 걸어요.
   - 올린 파일이 맞는지 검사한 뒤 써요.
3. 준비가 끝나면 `원격 호스트에 큰 파일 도구를 준비했어요`가 팀 알림에 보이고, 켜기를 이어서 해요.
4. 서버 셸에서 이 도구가 보이는 것은 원격 서비스가 다음에 다시 시작할 때부터예요. 그동안 호스트 상태에 `설정 대기 (원격 재시작 필요)`가 보일 수 있어요. 팀 작업에는 지장이 없어요.

준비에 실패하면 `원격 호스트에 큰 파일 도구를 준비하지 못했어요: …`가 떠요. 뒤에 붙는 이유를 보고 고친 뒤 다시 켜요.

| 이유 | 할 일 |
|---|---|
| `원격 호스트에 연결되어 있지 않아요. 연결된 뒤 다시 하세요` | 호스트 `⋯` → `다시 연결` 뒤 다시 켜요 |
| `원격 호스트에서 다른 작업이 진행 중이에요. 끝나면 다시 하세요` | 업데이트 같은 다른 작업이 끝나기를 기다려요 |
| `원격 호스트의 디스크가 가득 찼어요` | 서버의 디스크를 비워요 |
| `원격 호스트의 그 폴더에서는 프로그램을 실행할 수 없어요` | 서버 관리자에게 홈 폴더의 실행 제한(noexec)을 물어봐요 |

## 알아 두면 좋아요

- **원격 저장소에 올리기도 같아요.** `원격 저장소에 올리기…`를 누르면 큰 파일을 먼저 올리고, 그게 실패하면 코드도 올리지 않아요. 저절로 올리는 일은 없어요.
- **휴대폰·다른 PC에서도** 원격 팀을 보고, `메인 멈춤`을 켜고, 담당과 대화할 수 있어요. 반영 확인이나 폴더 지우기 같은 확인 단계는 이 PC에서만 해요([24장](24-phone-other-pc.md)).
- **컴퓨터 사용은 원격 팀에 없어요.** 서버에는 조작할 화면이 없기 때문이에요([18장](18-computer-use.md)).
- 팀 모드를 끄면 앱이 그 저장소의 큰 파일 설정을 켜기 전 상태로 되돌려요.

> **용어** 원격 호스트와 원격 저장소는 달라요. **원격 호스트**는 SSH로 연결한 서버(일하는 곳)예요. **원격 저장소**는 GitHub 같은 곳에 있는 Git 저장소(코드를 올려 두는 곳)예요.

## 조심하세요

> **주의** 큰 파일 저장소로 팀 모드를 쓴 서버를 지울 때는 순서를 지키세요. **먼저 팀 모드를 끄고**, 그다음 호스트 `⋯` → `목록에서 빼기…`에서 `원격 설치도 지우기`를 골라요. 순서가 바뀌면 그 저장소의 Git 설정이 지워진 도구를 가리켜서, 서버에서 `git` 명령이 큰 파일을 다루지 못할 수 있어요.

> **주의** 서버 연결이 끊겨도 서버의 팀은 출입증이 남은 동안 계속 일해요. 출입증이 끝나면 모델을 부르지 않고 안전하게 멈춰요. 오래 자리를 비울 거라면 프로젝트 메뉴의 `모든 영역 멈추기`를 먼저 눌러 두세요.
