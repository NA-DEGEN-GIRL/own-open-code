# 부록 A. 용어 사전

이 설명서에 나오는 낱말을 가나다순으로 모았어요. 뜻은 이 앱에서 쓰는 뜻이에요. 더 자세한 설명은 끝의 장 번호를 따라가세요.

## ㄱ

- **거부 앱(금지 앱)** — 컴퓨터 사용을 켜도 에이전트가 글자나 클릭을 보내지 않는 앱이에요. 터미널, 시작 메뉴와 검색, 이 앱, 비밀번호 관리자, 보안·관리자 창, 비밀번호 칸 등이에요. → [18장](18-computer-use.md)
- **게이트웨이** — 휴대폰이나 다른 PC가 이 PC의 대화에 붙는 입구예요. 이 PC 안(`127.0.0.1`)에서만 열려요. → [24장](24-phone-other-pc.md)
- **곁질문** — 에이전트가 일하는 동안 `/btw`로 이 대화에 대해 잠깐 묻는 질문이에요. 대화를 다 읽고 답하지만 도구를 쓰지 않고, 대화 기록에 남지 않아요. → [10장](10-conversation-tools.md)
- **계정** — 로그인 하나 또는 API 키 하나예요. 같은 회사의 계정을 여러 개 등록할 수 있어요(예: ChatGPT 01, ChatGPT 02). → [3장](03-first-account.md), [12장](12-multiple-accounts.md)
- **구독 계정** — ChatGPT나 Claude처럼 월 요금제로 쓰는 계정이에요. 돈 대신 5시간·주간 같은 사용 한도가 있어요. 구독 계정끼리는 앱이 자동으로 바꿔 쓰지 않아요. 이 PC의 Claude 구독 계정끼리만 `Claude 계정 사이`를 켰을 때 예외예요(처음 값은 `끄기`). → [12장](12-multiple-accounts.md), [20장](20-account-kinds.md)
- **기본 대화 폴더** — 폴더를 고르지 않고 시작한 대화가 일하는 폴더예요. 처음 값은 문서 폴더 안의 `Own OpenCode`이고, `설정` > `일반`에서 바꿔요. 사이드바에서는 `폴더 없는 대화` 묶음이에요. → [4장](04-first-conversation.md)
- **기기 권한** — 연결한 휴대폰·다른 PC가 할 수 있는 일의 범위예요. `읽기`, `메시지 보내기`, `전환`, `파일`, `터미널`, `관리`가 있어요. → [24장](24-phone-other-pc.md)
- **기록 이름** — Git의 브랜치(branch)를 쉬운 말로 부른 것이에요. 작업 한 줄기의 이름이에요. → [17장](17-team-mode.md)
- **끼워 넣기** — 에이전트가 일하는 중에 `Ctrl+Enter`(보내는 키가 `Enter`면 `Enter`)로 보낸 메시지예요. 지금 턴 안에서 다음 단계에 바로 읽혀요. → [10장](10-conversation-tools.md)

## ㄴ

- **내 지시문** — 내가 고친 지시문이에요. 개선판에서 Codex 방식은 기본 지시문, Pi 방식은 첫 문단, DeepSeek 방식은 모델 소개 줄만 내 글로 바꾸고, 나머지(승인 모드 설명, 도구)는 이 앱이 만들어요. `설정` > `에이전트 방식`에서 만들고 고치고 `기본으로 되돌리기`로 지워요. → [10장](10-conversation-tools.md)
- **노트** — 메모를 적어 두는 곳이에요. 대화 하나에 붙는 **대화 메모**(헤더 `⋯` → `대화 메모`, 처음에는 모델이 보지 않음), 프로젝트마다 여러 개를 두는 **프로젝트 노트**(대화 위 줄의 `노트` 단추), 어디에도 안 붙는 **아이디어 노트**(헤더의 전구 단추, `Ctrl+Alt+I`)가 있어요. 모두 연결한 모든 기기에서 같이 보여요. → [10장](10-conversation-tools.md)

## ㄷ

- **다른 PC** — 다른 PC의 데스크톱 앱에 등록한 이 PC(또는 반대로 이 PC에 등록한 다른 PC)예요. 사이드바의 `다른 PC` 아래에 보여요. 예전 이름은 원격 PC였어요. → [24장](24-phone-other-pc.md)
- **다른 도구의 대화** — 같은 프로젝트 폴더에서 Codex나 Claude Code로 나눈 대화예요. 이 앱에서 읽기만 하거나(공짜), `이어서 하기`로 옮겨 이어 가요. → [21장](21-import-other-tools.md)
- **대화 메모** — 대화 하나에만 붙는 짧은 메모예요. 예전 이름은 스레드 노트예요. `모델에게도 보이기`를 켜면 모델도 봐요. → [10장](10-conversation-tools.md)
- **대화 보기** — 대화 주변에 보일 정보(사용량 줄, 속도, 생각 과정 등)를 고르는 메뉴예요. 헤더의 눈 모양 단추예요. 화면에만 적용돼요. → [5장](05-screen-tour-theme.md)
- **담당** — 팀 모드에서 한 영역의 작업 폴더를 맡아 일하는 대화예요. 사용자가 담당에게 직접 말해도 돼요. → [17장](17-team-mode.md)
- **담당 대화 바꾸기** — 팀 모드에서 영역 폴더에 이미 있는 다른 대화를 그 영역의 담당으로 삼는 것이에요. 메뉴 이름은 `이 대화를 담당으로`예요. 옛 담당 대화는 보통 대화로 남아요. → [17장](17-team-mode.md)
- **담당 메모** — 팀 모드에서 담당이 팀에서 맡은 일을 사용자가 적어 두는 짧은 글이에요. 영역에 동료가 있을 때 담당과 동료가 서로 봐요. 담당 대화를 바꿔도 메모는 남아요. → [17장](17-team-mode.md)
- **대기열** — 에이전트가 일하는 중에 `Alt+Enter`(보내는 키가 `Enter`면 `Ctrl+Enter`)로 보낸 메시지가 차례를 기다리는 줄이에요. → [10장](10-conversation-tools.md)
- **데스크톱 앱** — 이 앱의 창이에요. 서비스에 붙어서 화면을 보여 줘요. 창을 닫아도 서비스의 일은 계속돼요. → [1장](01-what-is-it.md)
- **동료** — 팀 모드에서 영역 폴더의 담당 옆에 두는, 이름과 역할이 있는 대화예요(예: 시뮬, 리뷰어). 팀 메인이 일을 보낼 수 있지만 반영은 담당만 해요. 영역마다 4개까지예요. → [17장](17-team-mode.md)

## ㅁ

- **메인** — 두 곳에서 써요. ① 프리셋에서는 입력창에서 고른 계정·모델(이 대화를 이끄는 주인공)이에요. 하위 에이전트와 짝이 되는 말이고, 프리셋에는 메인 모델이 들어 있지 않아요. ② 팀 모드 화면 안의 `메인`은 늘 팀 메인(팀을 이끄는 대화)이에요. 영역의 계정·모델·추론 강도는 `모델`이라고 써요. → [14장](14-presets.md), [17장](17-team-mode.md)
- **메인 멈춤** — 팀 모드에서 그 영역에 새 일이 들어가지 않고 기다리게 하는 스위치예요. 팀 메인의 요청과 다른 영역의 물음·쪽지가 기다려요. 그 영역이 스스로 물어서 받는 답과 앱의 안내만 들어가요. → [17장](17-team-mode.md)
- **메인에게 넘기기** — 팀 모드에서 직접 작업을 끝내고 영역을 팀 메인에게 다시 맡기는 단추예요. 기다리던 메인 요청이 들어가고, 그동안 모아 둔 보고가 한 번에 팀 메인에게 가요. 담당에게 “메인한테 넘겨”라고 말해도 돼요. → [17장](17-team-mode.md)
- **멈춤 키(비상 정지)** — `Ctrl+Alt+Shift+Q`. 어디서 누르든 모든 세션의 컴퓨터 사용을 바로 멈춰요. `다시 허용`을 누를 때까지 멈춘 채예요. → [18장](18-computer-use.md)
- **모델** — 답을 만드는 인공지능 이름이에요(예: GPT-5.5, Claude Opus, DeepSeek). 같은 모델도 어느 계정으로 부르느냐에 따라 한도와 요금이 달라요. → [6장](06-model-account.md)
- **모델 묶음** — 프리셋의 한 방식(`모델 묶음에서 알아서`)이에요. 쓸 모델만 골라 두면 메인이 일마다 그중 하나를 골라 하위 에이전트에게 맡겨요. → [14장](14-presets.md)
- **모바일 미리보기** — 휴대폰 없이 Android 앱이 보는 화면을 PC의 휴대폰 크기 창으로 보는 기능이에요. → [25장](25-mobile-preview.md)
- **문맥 비우기** — 같은 대화에서 모델이 앞 대화를 보지 않게 새로 시작하는 것이에요(`/reset-context`, `/문맥비우기`). 대화에 `여기부터 새 문맥` 줄이 생기고, 지금 문맥의 시작인 동안 `되돌리기`로 돌아와요. 요약을 만들지 않아서 압축과 달라요. → [10장](10-conversation-tools.md)
- **문맥 창** — 모델이 한 번에 읽을 수 있는 대화 길이의 한도예요. 이 한도에 가까워지면 자동 압축이 일어나요. → [13장](13-auto-compaction.md)
- **물음** — 팀 모드에서 담당이나 동료가 다른 영역에 보내는 영역 메시지예요. 받는 쪽 차례를 하나 열고, 답이 새 차례로 돌아와요. 사용자에게 묻는 `질문`과는 다른 말이에요. → [17장](17-team-mode.md)

## ㅂ

- **반영** — 팀 모드에서 영역의 끝난 작업을 프로젝트 본 코드에 넣는 일이에요. 검사를 통과한 것만 들어가고 `되돌리기`가 있어요. → [17장](17-team-mode.md)
- **보내는 키** — 대화 입력창에서 메시지를 보내는 키예요. 처음 값은 `Ctrl+Enter`(macOS는 `⌘+Enter`)이고 `Enter`는 줄을 바꿔요. `전송` 옆 `▾`나 `설정` > `일반`에서 `Enter로 보내기`로 바꿀 수 있어요. → [4장](04-first-conversation.md)
- **보관함** — 보관한 세션이 모이는 곳이에요. 보관은 목록에서 잠시 치우는 것이고, 언제든 돌려놓아요. 삭제와 달리 대화가 남아요. → [5장](05-screen-tour-theme.md)
- **분할** — 한 창을 여러 칸으로 나눠 대화나 브라우저를 나란히 보는 것이에요. 4칸까지예요. → [19장](19-browser-pane.md)
- **브라우저 패인(앱 안 브라우저)** — 데스크톱 앱 안에 있는 에이전트 전용 브라우저예요. 세션마다 따로 있고, 진짜 마우스·키보드를 쓰지 않아요. → [19장](19-browser-pane.md)
- **브라우저 폴백** — 데스크톱 앱 대신 보통 웹 브라우저(Edge)로 여는 이 앱 화면이에요. `own open --browser`로 열어요. 앱 안 브라우저 같은 데스크톱 전용 기능은 없어요. → [2장](02-install-update.md), [19장](19-browser-pane.md)
- **비공식** — Claude 구독 계정에 붙는 표시예요. 서드파티 플러그인으로 연결하고, 약관 위험이 있어요. → [20장](20-account-kinds.md)

## ㅅ

- **서비스** — 이 PC에서 뒤에서 도는 프로그램이에요. 대화와 에이전트 일은 모두 여기서 돌아요. 창을 닫아도 계속 돌고, `own stop`으로 멈춰요. → [1장](01-what-is-it.md)
- **설명서** — 이 문서예요. 앱 안에서도 헤더의 `?` 단추로 열고, 인터넷이 없어도 돼요. → [1장](01-what-is-it.md)
- **세션** — 대화 하나의 기술 이름이에요. 화면에서는 `대화`라고 써요(`세션 ID`만 예외). 대화마다 모델 @ 계정, 승인 모드, 에이전트 방식, 컴퓨터 사용 같은 설정을 따로 가져요. → [4장](04-first-conversation.md)
- **속도** — 같은 모델을 더 빠르게 쓰는 설정이에요(표준, Fast, Ultrafast). 빠를수록 한도나 요금을 더 써요. → [16장](16-speed.md)
- **쉬는 중 · 대기 중** — `쉬는 중`은 지금 할 일이 없는 상태, `대기 중`은 줄을 서서 차례를 기다리는 상태예요(대기열, 대기함, 복원 대기). → [10장](10-conversation-tools.md), [17장](17-team-mode.md)
- **스킬** — 일하는 방법을 적어 둔 폴더(`SKILL.md`와 도움 파일)예요. 입력창의 ✦ `스킬`에서 고르고, `설정` > `스킬`이나 스킬 창에서 Codex·Claude Code의 스킬을 가져올 수도 있어요. 이 앱에 넣은 스킬은 모든 프로젝트에서 쓰고, 쓰지 않을 프로젝트에서만 꺼요. → [10장](10-conversation-tools.md)
- **승인 모드** — 에이전트가 파일을 고치거나 명령을 실행하기 전에 물을지 정해요. `읽기 전용`, `묻기`, `전체 허용`이 있어요. → [8장](08-approvals.md)
- **승인 요청 상자** — 에이전트가 허락이 필요한 일을 하려 할 때 입력창 바로 위에 뜨는 상자예요. `한 번 허용`, `항상 허용`, `거절…`로 답해요. → [4장](04-first-conversation.md), [8장](08-approvals.md)
- **실측·추정** — 한도와 사용량 숫자가 얼마나 믿을 만한지 붙이는 표시예요. 실측은 서버가 알려 준 값, 추정은 앱이 계산한 값이에요. → [7장](07-usage.md)
- **싼 시점** — 계정이나 모델을 바꿔도 손해가 적은 때예요. 압축 직후, 그리고 오래 쉬어서 캐시가 이미 식은 뒤예요. → [11장](11-cache-switch-cost.md)

## ㅇ

- **아이디어 노트** — 프로젝트와 상관없이 떠오른 생각을 쪽지처럼 붙여 두는 보드예요. `Ctrl+Alt+I`로 어디서든 빨리 적어요. 모델에게 보내지 않아요. → [10장](10-conversation-tools.md)
- **안내** — 팀 모드에서 앱이 담당이나 동료에게 보내는 짧은 소식이에요. 지켜본 영역이 반영 준비를 마쳤을 때, 물음에 답이 없을 때 와요. 사용자에게 오는 `알림`과는 달라요. → [17장](17-team-mode.md)
- **압축** — 대화 앞부분을 요약해서 짧게 만드는 일이에요. 문맥이 기준을 넘으면 자동으로 해요. 압축 직후는 계정을 바꾸기 좋은 때예요. → [13장](13-auto-compaction.md)
- **앱 연결** — Android 앱과 다른 PC의 데스크톱 앱이 쓰는 전용 입구예요. 이 PC가 만든 인증서의 지문만 믿어요. → [24장](24-phone-other-pc.md)
- **에이전트** — 대화만 하는 AI가 아니라, 내 프로젝트 폴더의 파일을 읽고 고치고 명령을 실행하는 일꾼 AI예요. 이 앱이 하는 일이 에이전트를 돌리는 것이에요. → [1장](01-what-is-it.md)
- **에이전트 방식** — 에이전트가 모델에게 어떤 지시문과 도구로 일을 시키는지예요. `Codex 방식`(처음 값), `Pi 방식`, `DeepSeek 방식`, `OpenCode 기본`이 있고, Codex·Pi·DeepSeek 방식에는 `지시문`(원본·개선판·내 지시문)도 골라요. 새 대화의 처음 값은 `설정` > `일반`에서 정해요. → [10장](10-conversation-tools.md)
- **여러 서비스 함께** — 웹 검색 한 번에 체크한 검색 서비스 모두에 묻고 결과를 합치는 방식이에요. 같은 페이지는 한 번만 넣고 여러 서비스가 함께 찾은 페이지를 앞에 둬요. `설정` > `웹 검색`의 `검색 방식`에서 골라요. → [8장](08-approvals.md)
- **연결 끊기** — 연결한 기기의 출입 자격을 없애는 것이에요(예전 이름은 폐기). 끊으면 그 기기는 바로 끊기고, 다시 쓰려면 QR부터 다시 연결해요. → [24장](24-phone-other-pc.md)
- **영역** — 팀 모드에서 동시에 진행하는 일 한 줄기예요. 작업 폴더 하나와 그 폴더를 맡은 담당 대화로 이뤄져요. 폴더 구역이 아니라 "하는 일" 단위예요. → [17장](17-team-mode.md)
- **영역 메시지** — 담당이나 동료가 팀 메인을 거치지 않고 다른 영역에 보내는 물음, 답, 쪽지예요. 팀 메인을 깨우지 않고, 다음 팀 소식에 적혀요. → [17장](17-team-mode.md)
- **울트라** — 스위치 하나로 추론 강도를 올리고, 하위 에이전트에게 적극적으로 맡기고, 안전 상한을 넓히는 기능이에요. 한도를 빨리 써요. → [15장](15-ultra.md)
- **원격 저장소** — GitHub 같은 곳에 있는 Git 저장소예요. 코드를 올려 두는 곳이에요. 원격 호스트와 다른 말이에요. → [17장](17-team-mode.md), [23장](23-remote-team.md)
- **원격 호스트** — SSH로 연결한 Linux 서버예요. 에이전트가 그 서버에서 일해요. → [22장](22-ssh-remote.md)
- **웹 검색 서비스** — 에이전트가 웹을 검색할 때 검색어를 보내는 곳이에요. `설정` > `웹 검색`에서 골라요. ChatGPT 계정이 있으면 `ChatGPT`(구독 사용량에서 빠짐)가 기본이에요. 키 없이 쓰는 무료 서비스(Exa, Parallel 등, 사용량 제한 있음), `DeepSeek`(검색어가 중국 서버로 가고 잔액에서 돈이 빠짐), `Brave`(직접 받은 키)도 고를 수 있지만 기본이 되지는 않아요. 키 없이 쓰는 서비스에 내 키를 넣으면 `Exa (내 키)`처럼 그 키로 검색하는 줄이 따로 생겨요(키는 이 PC의 키 저장소에만). `여러 서비스 함께`를 고르면 체크한 서비스 모두에 한 번에 묻고 결과를 합쳐요. 대화의 검색 카드 제목이 답한 서비스를 말해요. → [8장](08-approvals.md)
- **음성 입력** — 말한 내용을 글자로 바꿔 입력창이나 노트의 커서 자리에 넣는 기능이에요. 예전 이름은 받아쓰기예요. 저절로 보내지 않아요. 음성 입력 전용 키가 따로 필요해요. → [10장](10-conversation-tools.md)
- **이전 앱** — 예전에 쓰던 codex-multi-provider 앱이에요. 거기 저장한 로그인과 키를 `연결`하거나 `인수`해서 가져올 수 있어요. → [3장](03-first-account.md), [20장](20-account-kinds.md)
- **인증 브로커** — 이 PC에서 계정 키를 지키고, 원격 서버가 모델을 부를 때마다 출입증만 잠깐 빌려 주는 부분이에요. → [22장](22-ssh-remote.md)

## ㅈ

- **자동 전환** — 한도에 닿았을 때 앱이 다른 계정으로 저절로 바꾸는 것이에요. API 키 계정끼리, 그리고 이 PC의 Claude 구독 계정끼리만 돼요. → [12장](12-multiple-accounts.md)
- **작업 폴더** — Git의 worktree를 쉬운 말로 부른 것이에요. 한 저장소의 다른 줄기를 다른 폴더에 꺼내 두고 동시에 작업하는 방법이에요. 사이드바 프로젝트 줄의 `⑂` 단추로 만들어요. → [5장](05-screen-tour-theme.md), [17장](17-team-mode.md)
- **저장 지점** — Git의 커밋(commit)을 쉬운 말로 부른 것이에요. 파일 상태를 기록해 둔 한 지점이에요. → [17장](17-team-mode.md)
- **전환 비용** — 대화 도중 계정이나 모델을 바꿀 때 더 드는 비용이에요. 새 계정은 대화 전체를 처음부터 다시 읽어야 하기 때문이에요. → [11장](11-cache-switch-cost.md)
- **지문** — 열쇠(인증서, 호스트 키)의 고유 번호예요. 지문이 같으면 "진짜 그 PC·그 서버"라는 뜻이에요. SSH 호스트 키는 `SHA256:`으로 시작해요. → [22장](22-ssh-remote.md), [24장](24-phone-other-pc.md)
- **지시문** — 에이전트 방식이 모델에게 보내는 글이에요. `원본`(그 도구가 보내는 그대로), `개선판`(이 앱에 맞게 고친 판, 처음 값), `내 지시문`(내가 고친 판)이 있어요. `설정` > `에이전트 방식`에서 무엇을 보내는지 볼 수 있어요. → [10장](10-conversation-tools.md)
- **지켜보기** — 팀 모드에서 담당이 다른 영역을 “준비되면 깨워 달라”고 걸어 두는 것이에요. 그 영역이 반영 준비를 마치거나 반영되면 안내가 한 번 와요. 12시간 뒤 사라져요. → [17장](17-team-mode.md)
- **직접 작업 중** — 팀 모드에서 내가 담당 대화에 말해 그 영역을 직접 맡은 상태예요. 팀 메인의 새 요청은 내가 `메인에게 넘기기`로 넘길 때까지 기다리고, 시간이 지나도 저절로 끝나지 않아요. → [17장](17-team-mode.md)
- **쪽지** — 받는 대화를 깨우지 않는 영역 메시지예요. 그 대화에 다음 요청이 들어갈 때 함께 가요. → [17장](17-team-mode.md)

## ㅊ

- **추론 강도** — 모델이 답하기 전에 얼마나 오래 생각할지 정하는 값이에요. 높을수록 꼼꼼하지만 느리고 더 써요. → [6장](06-model-account.md)
- **출력 상한** — 모델이 한 번 답할 때 생각과 답을 합쳐 넘지 않을 양이에요. 문맥 창(읽을 수 있는 양)과는 달라요. 처음 값은 256,000을 넘기지 않기이고, `설정` > `출력 상한`에서 바꾸거나 보내지 않게 할 수 있어요. → [5장](05-screen-tour-theme.md#출력-상한-페이지)
- **출입증(lease)** — 원격 서버가 모델을 부를 때 이 PC가 잠깐 빌려 주는 열쇠예요. 기본 15분 뒤 끝나고, 서버 디스크에는 남지 않아요. 화면에도 출입증이라고 보여요(`출입증 시간(분)`). → [22장](22-ssh-remote.md)

## ㅋ

- **캐시** — 프로바이더가 같은 계정·같은 모델로 보낸 대화 앞부분을 기억해 두는 것이에요. 기억한 부분은 싸고 빠르게 읽어요. 시간이 지나면 식어서(잊어서) 다시 읽어야 해요. 상태는 `캐시 따뜻함`, `캐시 식는 중`, `캐시 차가움`으로 보여요. → [11장](11-cache-switch-cost.md)
- **캐시 재작성** — 캐시가 없는 계정·모델이 대화 전체를 처음부터 다시 읽는 것이에요. 긴 대화일수록 비싸요. → [11장](11-cache-switch-cost.md)
- **컴퓨터 사용** — 에이전트가 Windows 화면을 보고 진짜 마우스·키보드로 앱을 조작하는 기능이에요. 세션마다 켜요. → [18장](18-computer-use.md)
- **큰 파일 폴더** — 그림·소리·모델처럼 큰 파일이 모인 폴더예요. 팀 모드의 영역 폴더는 처음에 이 폴더를 받지 않고, 필요할 때만 가져와요. → [17장](17-team-mode.md), [23장](23-remote-team.md)

- **턴** — 메시지를 보낸 뒤 에이전트가 일을 마치고 멈출 때까지의 한 번이에요. 한 턴 안에서 모델을 여러 번 부를 수 있어요. → [4장](04-first-conversation.md)
- **토큰** — 모델이 글을 세는 단위예요. 한도와 요금은 토큰으로 세요. 앱은 한글을 글자당 약 0.65토큰으로 어림해요. → [7장](07-usage.md), [13장](13-auto-compaction.md)
- **팀 메인** — 팀 모드에서 일을 나눠 맡기는 대화예요. 일은 팀 메인에게 말하면 돼요. → [17장](17-team-mode.md)
- **팀 모드** — 한 프로젝트를 영역으로 나누고, 영역마다 담당 대화가 일하게 하는 기능이에요. → [17장](17-team-mode.md)
- **팀 지시문** — 팀 메인, 담당, 동료가 받는 지시문이에요. 앱이 정한 부분은 보기만 하고, `일하는 방식` 부분은 `설정` > `팀 모드` > `팀 지시문`에서 고쳐요(역할마다 2,000자까지). → [17장](17-team-mode.md)

- **포트 전달** — 밖에서 들어온 연결을 집 안의 이 PC로 넘겨주는 공유기·Windows 설정이에요. DDNS 경로에서 사용자가 직접 설정해요. → [24장](24-phone-other-pc.md)
- **프로바이더** — 모델을 제공하는 회사나 서비스예요(OpenAI, Anthropic, DeepSeek, xAI, OpenRouter 등). 화면에서는 `회사`나 `모델 회사`라고 써요. → [3장](03-first-account.md), [6장](06-model-account.md)

- **프로젝트 본 코드** — 팀 모드에서 영역의 작업이 모여드는 대상 줄기예요(보통 `main`). → [17장](17-team-mode.md)

## 영문

- **API 키** — 프로바이더 콘솔에서 받는 긴 비밀 글자예요. 쓴 만큼 돈을 내요. 앱은 이 PC에 암호화해 보관하고 끝 4자리만 보여 줘요. → [3장](03-first-account.md)
- **DDNS** — 집 인터넷 주소가 바뀌어도 늘 같은 이름으로 찾아오게 해 주는 서비스예요. 앱 연결의 바깥 길 중 하나예요. → [24장](24-phone-other-pc.md)
- **diff(변경 보기)** — 파일의 바뀌기 전 줄과 바뀐 뒤 줄을 비교해 보여 주는 화면이에요. 지운 줄은 빨강, 더한 줄은 초록이에요. → [8장](08-approvals.md), [9장](09-work-panel.md)
- **Fast·Ultrafast** — 속도 설정의 단계예요. 배지의 `×` 숫자는 한도를 그만큼 빨리 쓴다는 뜻이에요. → [16장](16-speed.md)
- **Git 저장소** — 파일이 바뀐 기록을 차곡차곡 남겨 두는 폴더예요. 안에 숨은 `.git` 폴더가 있어요. 기록 한 칸이 커밋(저장 지점), 기록의 줄기가 브랜치(기록 이름)예요. 팀 모드와 작업 폴더는 Git 저장소에서만 쓸 수 있어요. 아니면 프로젝트 줄의 흐린 `팀` 단추 → `Git 저장소로 만들기…`로 만들어요. → [9장](09-work-panel.md), [17장](17-team-mode.md)
- **Git LFS** — Git이 큰 파일을 따로 보관하는 방법이에요. 원격 서버에 도구가 없으면 앱이 한 번 올려 줘요. → [23장](23-remote-team.md)
- **`own` 명령** — 서비스를 켜고 끄고 상태를 보는 PowerShell 명령이에요(`own status`, `own start`, `own stop`, `own restart`, `own rollback`). → [2장](02-install-update.md)
- **MCP 레지스트리** — 공개된 MCP 서버를 모아 둔 공식 목록(`registry.modelcontextprotocol.io`)이에요. `설정` > `MCP 서버`의 `찾아서 설치…`가 여기서 찾아요. 올라온 서버는 모두 다른 사람이 만든 프로그램이에요. → [10장](10-conversation-tools.md)
- **MCP 서버** — 에이전트에게 도구를 더해 주는 프로그램이나 주소예요. `설정` > `MCP 서버`에서 더하거나 Claude Code·Codex에서 가져오거나 MCP 레지스트리에서 찾아 설치하고, 켜고 꺼요. 더한 서버는 모든 프로젝트에서 쓰고, 쓰지 않을 프로젝트에서만 꺼요. → [10장](10-conversation-tools.md)
- **PowerShell** — Windows에 들어 있는 명령 창이에요. 시작 메뉴에서 "PowerShell"을 찾아 열고, 명령을 적은 뒤 `Enter`를 눌러요. `own` 명령은 Claude 앱과 상관없는, 이렇게 새로 연 창에서 실행해요. → [1장](01-what-is-it.md), [2장](02-install-update.md)
- **SSH** — 다른 컴퓨터(주로 Linux 서버)에 안전하게 접속하는 표준 방법이에요. → [22장](22-ssh-remote.md)
- **t/s** — 1초에 나온 토큰 수(출력 속도)예요. 턴 아래 한 줄에 보여요. 앞에 `≈`가 붙으면 어림값이에요. → [7장](07-usage.md)
- **Tailscale** — 내 기기들끼리만 보이는 사설 네트워크를 만들어 주는 프로그램이에요. 같은 계정에 로그인한 기기끼리만 닿아요. 설치와 설정은 사용자가 직접 해요. → [24장](24-phone-other-pc.md)
